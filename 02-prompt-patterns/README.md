# 02 — Prompt Patterns

Reusable ways to approach common thinking tasks. Select a pattern, give it the relevant material and define the output. Patterns can be combined in a workflow.

| Pattern | Use it when | Typical output |
|---|---|---|
| [Planner](planner.md) | Work is ambiguous or multi-step | Plan, dependencies, questions, milestones |
| [Analyst](analyst.md) | You need insight from information or data | Findings, comparisons, options, caveats |
| [Summarizer](summarizer.md) | You need to reduce a large body of content | Concise summary, decisions, actions, open items |
| [Critic](critic.md) | A draft needs challenge or quality review | Issues ranked by impact, corrections, questions |
| [Formal Verification Mode](formal-verification-mode.md) | Correctness, assumptions, evidence and uncertainty need explicit review | Structured assessment, consistency checks, calibrated judgment |
| [Coach](coach.md) | You need to learn, prepare or improve | Explanation, practice, feedback, next steps |

**Tip:** for an important deliverable, use Planner → Analyst/Summarizer → Critic → human approval. Add [Formal Verification Mode](formal-verification-mode.md) when claims, calculations or evidence need a more explicit check. For consequential work, follow [the verification loop](../01-foundations/verification.md); AI review is not a substitute for independent verification.
