# Presentations

## Create a presentation outline

> Create a `[number]-slide` outline for `[audience]` to achieve `[purpose]`. Use the supplied source material only. For each slide provide: message-led title, one key point, supporting evidence, suggested visual and speaker-note intent. Build a logical narrative from context to conclusion. Do not invent data or case studies.

## Convert a report into slides

> Turn this report into a presentation for `[audience]`. Preserve the report's conclusions and caveats. Prioritise the few insights needed for the decision. Include an appendix slide for detail that should not be lost. Flag any statement that needs human confirmation before presentation.

## Improve an existing deck

> Review this deck for narrative, audience fit, slide density, clarity, accessibility and evidence. Identify the five highest-impact improvements. For each, reference the slide, explain the issue and suggest a concrete change. Do not add unsupported claims or decorative content that does not advance the message.

## Prepare speaker notes

> Draft natural speaker notes for each slide for a `[duration]` presentation. Explain the significance of each chart and the transition between slides. Do not simply read slide text aloud. Mark any chart or claim that needs verification.

**Human check:** data and chart integrity, brand rules, accessibility, image rights, audience confidentiality and whether recommendations are authorised.
