# Planning and Projects

## Scope a piece of work

> Help scope `[initiative]` for a small team. Define the problem, desired outcome, in-scope and out-of-scope work, stakeholders, assumptions, constraints, dependencies, risks and acceptance criteria. Identify decisions that need a sponsor. Mark unknowns instead of filling them in.

## Create a simple action plan

> Convert this objective into a practical action plan for `[team/period]`. Keep it proportionate. Include sequence, owner role, inputs, dependencies, evidence of completion and check-in points. Use `TBC` for missing owners or dates.

## Prepare a daily execution brief from connected sources

If your approved AI tool can access relevant email, task and meeting sources, ask it to synthesize a short brief. This requires configured integrations and appropriate permissions; a prompt alone does not grant access.

> Using only the connected sources you are authorised to access, prepare my daily execution brief for `[date]`. Review assigned tasks and due dates, relevant unread or flagged email, and upcoming meetings with their available context. Rank proposed priorities using deadlines, explicit commitments, blockers and business impact. For each item, include the source and date, why it matters, next action and any dependency. Draft a short agenda or preparation checklist for each important meeting. Flag conflicting deadlines, missing context and uncertain inferences. Do not create tasks, send messages or change records. Finish with the questions I need to resolve.

Treat the output as a proposed plan, not an authoritative representation of everything in your workload. Check source coverage, dates, duplicate items and any conflicting information.

## Retrospective

> Facilitate a constructive retrospective using these notes. Group observations into what helped, what hindered, surprises and changes to try next. Distinguish symptoms from root-cause hypotheses. Suggest no more than five actionable improvements with a way to tell whether each helped.

## Stakeholder update

> Create a stakeholder update from the supplied project facts. Tailor the detail to `[audience]`. State progress, changes, impact, risks, decisions required and next communication date. Do not hide bad news or overstate confidence.

**Human check:** ownership, capacity, dates, dependencies, risk acceptance and sponsor decisions. For connected-source briefs, verify source coverage and all deadlines before acting.
