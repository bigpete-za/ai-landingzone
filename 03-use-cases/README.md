- [Presentations](presentations/README.md) — outline, create and critique.

- [Data and spreadsheets](data/README.md) — understand tables, analyse trends and explain results.
- [Planning and projects](planning/README.md) — scope work and track delivery.

## Prompt safety

Use approved sources and tools. For organisational questions, tell the model which documents are authoritative. Do not ask it to invent a policy, metric, quotation, owner, date or commitment. Always review before sending or publishing.
