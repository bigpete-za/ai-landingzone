# Research

## Build an evidence-backed brief

> Research `[question]` for `[audience and purpose]` as of `[date]`. Prioritise primary and authoritative sources. Return an executive summary, key findings, evidence and source links, areas of disagreement, uncertainties and questions for further research. Distinguish source facts from your synthesis. Do not invent citations. State when a claim cannot be verified.

## Compare options or suppliers

> Compare `[options]` against these criteria: `[criteria and relative importance]`. Use the supplied sources only / search for authoritative public sources `[choose one]`. Return a comparison table, evidence per criterion, missing information, risks, assumptions and questions to ask each supplier. Do not rank an option where evidence is insufficient.

## Test a claim

> Assess the claim: `[claim]`. Find the strongest evidence for and against it. Prioritise original research, official documentation and direct statements. Record publication dates and the date of the underlying event where relevant. Explain what the evidence does and does not establish. Give a confidence assessment with reasons.

## Create a source register

> Create a source register for `[topic]` with title, publisher, URL, publication/update date, source type, relevance, key claim supported and caveats. Flag duplicate, outdated or low-authority sources. Do not use search-result snippets as substitutes for reading the source.

**Human check:** source authority, dates, primary evidence, commercial bias, regional applicability and direct support for each claim.
