# Which Copilot Tool When?

Choose the surface that has the **right task context**. The best tool is not necessarily the newest or most feature-rich one.

| Work to do | Start here | Why / watch-outs |
|---|---|---|
| General question, brainstorming, explain a concept, work from an uploaded file or public web sources | Microsoft Copilot Chat | Good general assistant. Confirm whether the current experience is web-grounded or has access to your work data. |
| Draft or refine a document, restructure text, summarise a supplied document | Word with Copilot | Best when the document itself is the working artefact. Review facts, formatting and version history. |
| Analyse tabular data, explain a formula, explore trends | Excel with Copilot | Use when the workbook is the source. Check formulas, ranges, filters and calculations independently. |
| Build or refine a slide deck | PowerPoint with Copilot | Useful for turning source material into a narrative and slides. Check claims, chart data, design and image rights. |
| Draft replies, summarise email threads, manage communication | Outlook with Copilot | Use the actual thread and mailbox context where available. Review recipients, tone and commitments before sending. |
| Prepare for, catch up on or follow up a meeting | Teams with Copilot | Meeting content depends on the meeting context and tenant settings; check transcript/recording availability and participant expectations. |
| Ask questions over approved internal content | Work-grounded Copilot experience / approved agent | Confirm licence, permissions, indexed sources and access scope. Do not assume all company data is available. |
| A repeatable task with a stable procedure, bounded knowledge and multiple steps | An approved agent or skill | Define scope, allowed sources, permissions, human checkpoints and failure behaviour before deployment. |

## Quick decision path

1. **Is this a general question or public research?** Start in Copilot Chat; ask for sources and verify current facts.
2. **Is the work centred on an open Office artefact?** Work in its app: Word, Excel or PowerPoint.
3. **Does the task depend on mail, meetings or chat history?** Use Outlook or Teams where the relevant context is available and permitted.
4. **Does it require internal knowledge?** Use an experience explicitly grounded in approved organisational content; confirm it can access the intended source.
5. **Is it repeatable and multi-step?** Consider an approved agent/skill only after the process, permissions and approval points are clear.

## Important caveats

- Copilot Chat, Microsoft 365 Copilot, app-embedded experiences and agents are not identical products or capabilities.
- Grounding, feature access and app integration vary by licence, tenant configuration, region, app version and admin policy.
- A user's Microsoft 365 permissions continue to matter. Copilot is not a reason to broaden access; review oversharing and stale permissions.
- A generated answer is not proof that every relevant file, message or source was searched.
- Confirm the current behaviour in [Microsoft Copilot overview](https://learn.microsoft.com/en-us/copilot/overview), [requirements](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-chat-requirements) and [Microsoft Adoption](https://adoption.microsoft.com/en-us/Copilot/).
