# Licensing and Attribution

This repository is inspired by public prompt and skill collections. Inspiration does not mean their content can be copied without conditions.

## Default approach

- Link to upstream examples and keep their original attribution and licence notices intact.
- Write original prompts and workflows for this repository wherever practical.
- Do not mirror large prompt collections or download/copy sample assets simply because they are public on GitHub.
- Before adapting or redistributing a third-party sample, inspect the licence applying to that exact repository and file, including any separate asset licences or notices.
- Record source, author (when available), licence, changes made and date checked for any reused material.

The repository owner should confirm the licence of this repository and ensure third-party material is compatible. Do not assume every linked webpage, image, logo, prompt or document is covered by a repository's top-level software licence. When in doubt, link rather than copy or seek permission.
