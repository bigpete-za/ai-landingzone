# AI Glossary

| Term | Plain-language definition |
|---|---|
| AI (artificial intelligence) | A broad field of systems that perform tasks associated with human intelligence, such as recognising patterns, generating content or making predictions. |
| Generative AI | AI that creates new text, images, audio, video, code or other content from a prompt and context. |
| Large language model (LLM) | A model trained on large amounts of text to process and generate language. It can produce fluent output without guaranteeing factual accuracy. |
| Prompt | The instruction, question and context supplied to an AI system. |
| Prompt pattern | A reusable way to structure a task, such as planning, summarising or critique. |
| Prompt library | A maintained collection of reusable prompts with descriptions, inputs and review information. |
| Context | Information available to the model for the current task, including instructions, conversation, files or connected sources. |
| Grounding | Connecting a response to specified sources or data instead of relying only on general learned patterns. |
| Hallucination | A plausible-sounding but unsupported or incorrect generated claim. |
| Retrieval-augmented generation (RAG) | A design that retrieves relevant information from a knowledge source and provides it to a model as context. |
| Agent | An AI system configured to pursue a goal using tools, data or multiple steps, sometimes with limited autonomy. |
| Skill | A reusable procedure that describes how to complete a task consistently; support and execution vary by platform. |
| System/custom instructions | Persistent or higher-level guidance that shapes how an assistant responds. Product terminology and precedence differ. |
| Token | A unit of text or other content processed by a model. Token limits affect how much context can be supplied. |
| Fine-tuning | Additional training that adjusts a model's behaviour for a narrower task or domain; not the same as prompting or attaching documents. |
| Human-in-the-loop | A workflow where a person reviews or approves output or actions at defined points. |
| Data leakage | Unintended exposure of information to people, services or systems not authorised to receive it. |
| Prompt injection | Malicious or accidental instructions embedded in content that attempt to manipulate a model's behaviour. |
| Evaluation | A structured way to test quality, reliability, safety and usefulness against defined criteria. |
| AI literacy | The knowledge and skills needed to understand, use, evaluate and question AI appropriately. |
