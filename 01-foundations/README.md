# 01 — Foundations

The habits that make AI useful and safe matter more than elaborate prompt syntax.

- [AI mindset](ai-mindset.md) — what generative AI is good at, where it fails, and the human role.
- [Planning](planning.md) — define the task, context, source material and expected output.
- [Context and memory](context-memory.md) — give the model the information it needs without assuming it remembers.
- [Verification](verification.md) — check claims, sources, calculations and suitability.
- [Safe use](safe-use.md) — protect information, respect permissions and keep humans accountable.

Recommended order: mindset → safe use → planning → context → verification.
